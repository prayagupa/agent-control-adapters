# LangChain examples

Choose the complete [native Agent Hooks folder](agent_hooks/) or
[native ACS folder](acs/). Both show the actual application-owned `create_agent`
builder, middleware, model/client setup, policies, tools, run, errors and cleanup.
ACS includes YAML/Rego assets; each folder has standalone requirements.

See the [installation, profile and lifecycle guide](../../docs/langchain/README.md).
There are no fabricated model responses. Obtain explicit approval and an
exclusive local-Qwen slot before executing the required model/copy gates.
