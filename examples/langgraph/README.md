# LangGraph examples

Choose the complete [native Agent Hooks folder](agent_hooks/) or
[native ACS folder](acs/). Each contains standalone requirements and complete
`llm_hooks.py` / `tool_hooks.py` setup; ACS includes YAML/Rego assets.

See the [installation, profile and lifecycle guide](../../docs/langgraph/README.md).
All model output comes from the operator-managed local Qwen model. Required
real-model and copied-folder gates need explicit approval and an exclusive model slot.
