# agent-control-langgraph

Native, single-use LangGraph controls. The application builds and owns its graph,
model, tools, clients, and event loop.

See the [LangGraph guide](https://github.com/prayagupa/agent-control-adapters/blob/main/docs/langgraph/README.md) and
[complete examples](https://github.com/prayagupa/agent-control-adapters/tree/main/examples/langgraph/).

Unpublished alpha; review the [security notice](https://github.com/prayagupa/agent-control-adapters/blob/main/SECURITY.md) before deployment.
