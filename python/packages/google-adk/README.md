# Agent Hooks for Google ADK

An independently installed, single-use async adapter for the pinned Google ADK
native runner. It supports native Agent Hooks and optional ACS/Rego policies
without copying a governance engine or changing caller-owned models.

See the [adapter guide](https://github.com/prayagupa/agent-control-adapters/blob/main/docs/google-adk/README.md)
and [standalone examples](https://github.com/prayagupa/agent-control-adapters/tree/main/examples/google-adk/).

Unpublished alpha; review the [security notice](https://github.com/prayagupa/agent-control-adapters/blob/main/SECURITY.md) before deployment.
