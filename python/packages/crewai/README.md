# agent-hooks-crewai

Execution-scoped Agent Hooks and ACS integration for CrewAI.

See the [CrewAI adapter guide](https://github.com/prayagupa/agent-control-adapters/blob/main/docs/crewai/README.md) for installation,
API usage, supported execution, and lifecycle requirements, and the
[complete example guide](https://github.com/prayagupa/agent-control-adapters/blob/main/docs/crewai/examples.md) for runnable applications.

This package is an unpublished alpha. Review the
[security notice](https://github.com/prayagupa/agent-control-adapters/blob/main/SECURITY.md#known-dependency-release-blocker) before deployment.
