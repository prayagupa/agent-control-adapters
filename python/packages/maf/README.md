# agent-hooks-maf

ACS policy controls through Microsoft Agent Framework's native Agent Hooks
middleware. This adapter does not replace the native framework integration or
implement a second policy evaluator.

See the [MAF guide](https://github.com/prayagupa/agent-control-adapters/blob/main/docs/maf/README.md) for source installation, supported
runtime configuration, examples, and enforcement limits.

This package is an unpublished alpha. Review the [security notice](https://github.com/prayagupa/agent-control-adapters/blob/main/SECURITY.md) before
deployment.
