# agent-hooks-adapters

Typed execution contracts for Agent Hooks and ACS controls in agent frameworks.

See the [shared API reference](https://github.com/prayagupa/agent-control-adapters/blob/main/docs/api.md) for policy sources,
per-agent bindings, run results, and errors. Choose a supported integration in
the [adapter guides](https://github.com/prayagupa/agent-control-adapters#get-started).

This package is an unpublished alpha. Review the [security notice](https://github.com/prayagupa/agent-control-adapters/blob/main/SECURITY.md) before
deployment.
