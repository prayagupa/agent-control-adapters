# agent-hooks-langchain

Native, single-use LangChain middleware controls. The application visibly calls
`create_agent` and owns its model, tools, clients, and event loop.

See the [LangChain guide](https://github.com/prayagupa/agent-control-adapters/blob/main/docs/langchain/README.md) and
[complete examples](https://github.com/prayagupa/agent-control-adapters/tree/main/examples/langchain/).

Unpublished alpha; review the [security notice](https://github.com/prayagupa/agent-control-adapters/blob/main/SECURITY.md) before deployment.
