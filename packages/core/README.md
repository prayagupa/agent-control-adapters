# agent-hooks-adapters

Typed execution contracts for Agent Hooks and ACS controls in agent frameworks.

See the [shared API reference](../../docs/api.md) for policy sources,
per-agent bindings, run results, and errors. Choose a supported integration in
the [adapter guides](../../README.md#get-started).

This package is alpha. Review the [security notice](../../SECURITY.md) before
deployment.
